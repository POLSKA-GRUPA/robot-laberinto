# 🤖 ROBOT: Laberinto de Plataformas

> 🧸 **NUEVO:** elige personaje al arrancar — **ROBOT** o **BUDY** (el muñeco de Natalia)

Juego 3D de plataformas en el navegador con un robot diseñado por Natalia (Tripo AI).

## 👉 JUGAR AQUÍ

**[https://polska-grupa.github.io/robot-laberinto/](https://polska-grupa.github.io/robot-laberinto/)**

No hace falta descargar nada: abre el enlace y juega.

## 📱 Instalarlo en el móvil como una app

**iPhone (con Safari):**
1. Abre el enlace de JUGAR en Safari
2. Toca el botón Compartir (cuadrito con flecha hacia arriba)
3. Elige "Añadir a pantalla de inicio"

**Android (con Chrome):**
1. Abre el enlace de JUGAR en Chrome
2. Toca "Instalar aplicación" (o menú de tres puntos y luego Instalar)

Una vez instalado tiene su propio icono, va a pantalla completa y funciona sin internet.

## 🎮 Controles

- **Ordenador:** flechas o WASD para moverte, ESPACIO para saltar, R reinicia el nivel
- **Móvil:** joystick táctil a la izquierda, botón SALTAR a la derecha

## 🎯 El juego

17 niveles de dificultad creciente: plataformas estáticas, móviles y que se caen, con un portal al final de cada nivel. Guarda tu progreso automáticamente.
